# 🛒 Your Electronixs

A modern e-commerce web application built with **Flask**, **SQLite**, **HTML**, **CSS**, and **JavaScript**. The application allows users to register, log in, browse products, search, filter, manage their cart, and place orders through a responsive interface.

## ✨ Features

- User Authentication
- Product Catalog
- Search & Category Filter
- Shopping Cart
- Checkout System
- Responsive Design

## 🛠️ Tech Stack

- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```
your_electronixs/
├── app.py
├── requirements.txt
├── templates/
├── static/
├── instance/
└── README.md
```

## 🚀 Installation

```bash
git clone https://github.com/yourusername/your_electronixs.git
cd your_electronixs

python -m venv venv

# Windows
venv\Scripts\activate

# Linux/macOS
source venv/bin/activate

pip install -r requirements.txt
python app.py
```

Open your browser and visit:

```
http://localhost:5000
```
